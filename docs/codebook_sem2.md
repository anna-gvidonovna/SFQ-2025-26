# Кодбук — `combined_general_agg_sem2.csv` (семестр 2)

Анкета оценки студенческого опыта (SFQ), 2025–26, **семестр 2**.
Источник: выгрузки из системы Тестограф (xlsx), 18 программ, 317 респондентов.

> **Отличия от семестра 1** (важно при объединении данных):
> - Нет вопроса `satisf_teachers` (общая удовлетворенность преподавателями).
> - `prev_sem_relevance` и `skill_confidence` оценивались по шкале **1–4** (в семестре 1 — 1–5),
>   поэтому средние по этим метрикам между семестрами **несопоставимы**.
> - Добавлены три новых вопроса по шкале **1–7**: `goal_achieved`, `navigation_ease`, `class_comfort`.
> - В общем файле нет блоков `gen_ed_*` / `hum_*` (оценки по дисциплинам — в файле преподавателей).
> - Поле «Оставьте свои контакты» **исключено** из данных как персональные данные (PII).

## Общие правила шкал
- Матричные вопросы (`*_score`, `*_imp`): **1–4**.
- `satisf_overall`, `expect_match`: **1–4**.
- Блоки `assess_*`, `infra_*`: **1–5**.
- `prev_sem_relevance`, `skill_confidence`: **1–4** (в семестре 1 — 1–5).
- `goal_achieved`, `navigation_ease`, `class_comfort`: **1–7**.
- `nps`: **0–10**.
- `postgrad_*`: текст выбранного варианта (заполнено = выбрано, пусто = не выбрано). Это **не** числовая шкала.
- `*_comment`: открытые текстовые ответы (возможны переносы строк).
